Authentication

Secure from the start

1

Register

Name, email, password (min 8 chars) — sends a 6-digit OTP to your inbox.

2

Verify Email

Enter the OTP to activate your account. Resend available.

3

Sign In

Email + password. Optional 2FA step if enabled.

4

Password Reset

Forgot password → OTP code → new password. Fully OTP-based, no magic links.

Security Features
✓ JWT access + refresh tokens
✓ Two-Factor Authentication (email OTP)
✓ BCrypt password hashing
✓ Route guards (auth + guest)
✓ Session timeout with countdown
✓ User data isolation (no cross-access)
⏱ Session Timeout
After 120 seconds of inactivity a warning dialog appears. Continue or sign out — auto logout if no response.

Insights

Smart observations, automatically

Budgetix analyses your transactions and generates personalised insights — every 1st of the month, or on demand.

✦ POSITIVE
Your savings rate of 39% is excellent!
You're saving more than 3× the recommended 10% benchmark. Keep it up.
⚠ NEGATIVE

ℹ INFO
4 recurring subscriptions — $87/month
Netflix, Spotify, Adobe CC, and iCloud detected.
◆ WARNING
Entertainment budget exceeded by 15%
Consider adjusting your budget for next month.
INSIGHT TYPES
+High savings rate, Spending decrease, Goal milestone
−Low savings rate, Spending increase, Unusual spending, Budget exceeded
iSubscription summary, Monthly summary
!Income change, Budget on track
🗓 Auto-generated
Every 1st of the month at 08:00 UTC for all verified users. Also triggered manually with the "Generate Insights" button.
Each insight can be dismissed with the ✕ button. Dismissed insights are permanently removed from the list.
