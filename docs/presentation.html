Authentication

Secure from the start

1

Register

Name, email, password (min 8 chars). Triggers a 6-digit OTP email.

2

Verify Email

Enter the OTP to activate your account. Resend available if needed.

3

Sign In

Email + password. Optional 2FA step if enabled — sends a second code.

4

Password Reset

Forgot password → OTP code to inbox → set new password. No magic links.

Security Features
✓ JWT access token + refresh token rotation
✓ Two-Factor Authentication (email OTP)
✓ BCrypt password hashing (cost 12)
✓ Route guards (auth + guest)
✓ Session timeout with countdown (120 s)
✓ Full user data isolation
⏱ Session Timeout
After 120 s of inactivity a warning dialog counts down. Click Continue to stay, or Sign Out. Auto-logout if no response.

Categories & Auto-Categorization

Smart tagging, zero effort

Define keyword rules once — every matching transaction is categorized automatically on import or creation.

└─Fuel

System categories are pre-seeded for all users. User-created categories belong only to that account.
AUTO-CATEGORIZATION RULES
Keyword → Category mapping
netflix → Entertainment
uber → Transport
salary → Income / Salary
lidl → Food / Groceries
HOW IT WORKS
1
Add keyword rules to a category via POST /categories/{id}/rules
2
When a transaction is created without a category, the backend scans its description
3
First matching keyword rule wins — category is assigned automatically

Recurring Transactions

Set it once, forget it

Define a rule — the backend scheduler runs every hour and posts the transaction automatically on due date.

EXAMPLE RULE
DescriptionNetflix Subscription
Amount−$15.99
TypeEXPENSE
FrequencyMONTHLY
Start Date2026-01-01
AccountBarclays Current
6 FREQUENCIES
Daily Weekly Bi-weekly Monthly Quarterly Yearly
WHAT HAPPENS EACH RUN (hourly scheduler)
1
Finds all rules where next_run ≤ now and isActive = true
2
Creates a Transaction record automatically
3
Updates Account balance
4
Updates matching Budget spent
5
Advances next_run to next occurrence date
6
Sends an in-app notification to the user
Use Toggle to pause/resume without deleting. Set an End Date to auto-deactivate after a specific date.
